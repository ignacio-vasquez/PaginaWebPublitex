# Pendientes

## Skills para instalar más adelante

El usuario pidió posponer la instalación. Cuando diga «veamos las skills», retomar e instalar las tres recomendadas del catálogo oficial `openai/skills`:

- `playwright`: comprobar visualmente la web y probar navegación, formularios y botones.
- `pdf`: leer, crear y revisar PDFs, incluidos presupuestos, facturas y logos.
- `security-best-practices`: revisar seguridad de cuentas, permisos y archivos adjuntos.

No instalarlas antes de que el usuario retome el tema. Revisar disponibilidad y requisitos actuales al instalar.

Otras opciones mencionadas, sin selección para instalar: `figma-implement-design`, `gh-fix-ci`, `render-deploy` y una skill personalizada de Publitex.
